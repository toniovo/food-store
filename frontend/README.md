# Food Store - Frontend Web App

Esta es la interfaz web que desarrolle para el sistema de gestion de pedidos. Esta configurada para que consuma datos simulados haciendo fetch a archivos JSON locales, manteniendola completamente independiente del backend.

## Tecnologias Utilizadas
* HTML5 y CSS3
* TypeScript
* Vite

## Instrucciones de Ejecucion
Para ejecutar el entorno de desarrollo local, se deben seguir estos pasos:
1. Instalar dependencias: npm install
2. Iniciar el servidor: npm run dev
3. Abrir la direccion local generada en el navegador web (por defecto http://localhost:5173).
